# StegVerse Core-Lite
Minimal footprint bundle for external developers.

Includes:
- Ingestion pipeline
- Basic telemetry (StegDB)
- Governance core (ALLOW/DENY/FAIL_CLOSED)
- TV/TVC ephemeral auth

Does NOT include:
- Entity coordination bridge
- Cost accounting
- Deterministic gates
- Consensus
- Vault adapter

For full features, upgrade to Core-Addons or Core-Master.
